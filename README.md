# aqparaq

Карьерный смарт-агрегатор для студентов и молодых специалистов. Дашборд в стиле
TradingView: вакансии, стажировки, чемпионаты и хакатоны с Match Score и
анализом Skill Gap.

## Стек

- **Next.js 16** (App Router) + TypeScript
- **Tailwind CSS 4**
- Моковые данные: `src/data/db.json`

## Запуск

```bash
npm install
npm run dev
```

Приложение будет доступно на [http://localhost:3000](http://localhost:3000).

```bash
npm run build   # production-сборка
npm run lint    # проверка ESLint
```

## Структура

- `src/app` — страницы (Лента `/`, карточка вакансии `/jobs/[id]`, Личный
  кабинет `/profile`)
- `src/components` — UI-компоненты (layout, dashboard, profile, ui)
- `src/lib` — работа с данными, типы, тема (dark/light)
- `src/data/db.json` — моковая база: вакансии/стажировки/чемпионаты/хакатоны,
  профиль пользователя, партнёры вуза, каталог курсов

## Реализованный функционал

- Лента с вкладками (Вакансии / Стажировки / Чемпионаты / Хакатоны),
  фильтрацией и сортировкой
- Match Score и Skill Gap индикатор с рекомендацией курса на каждой карточке
- Внешняя ссылка на первоисточник в каждой карточке
- Личный кабинет: CV, ссылки на LinkedIn/GitHub, университетский блок (GPA,
  оценки, навыки), B2B-виджет вакансий от партнёров вуза, каталог
  дополнительных курсов, достижения (геймификация)
- Тёмная/светлая тема
- Заглушки "Скоро": MOCK-интервью с ИИ, Alumni Network, AI-карьерный трек,
  менторство
